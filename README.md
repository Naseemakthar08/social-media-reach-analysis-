Social Media Reach & Engagement Analysis

📌 Project Overview

This project analyzes social media post performance across multiple platforms to understand reach, impressions, engagement, and engagement rate.

The analysis was performed using Microsoft Excel, with the goal of identifying patterns in social media performance and understanding which platforms and content types generate better audience engagement.

«Note: The dataset is simulated and created for learning and practice purposes. It does not represent real social media data.»

---

🎯 Objectives

- Analyze social media reach and impressions.
- Compare performance across different platforms.
- Measure audience engagement.
- Identify high-performing content types and categories.
- Analyze engagement rate and reach rate.
- Create an interactive dashboard for performance monitoring.
- Generate insights that can support better social media content strategies.

---

🗂️ Dataset

The dataset contains social media post-level information from January 1, 2025 to July 29, 2025.

Platforms Covered

- Instagram
- Facebook
- Twitter/X
- LinkedIn
- TikTok

Dataset Features

Column| Description
Post ID| Unique identifier for each post
Date| Date of publication
Post Time| Time of publication
Platform| Social media platform
Post Type| Type of content posted
Content Category| Category or purpose of the content
Followers at Posting| Number of followers at the time of posting
Reach| Number of users reached
Impressions| Total number of times content was displayed
Likes| Number of likes
Comments| Number of comments
Shares| Number of shares
Total Engagements| Sum of likes, comments and shares
Engagement Rate| Engagements relative to reach
Reach Rate| Reach relative to followers

🧮 Important Calculations

Engagement Rate

Engagement Rate = Total Engagements / Reach

Reach Rate

Reach Rate = Reach / Followers at Posting

Total Engagements

Total Engagements = Likes + Comments + Shares

---

⚠️ Dataset Assumptions

- The dataset is simulated for educational purposes.
- The data covers five social media platforms.
- Reach is modeled using platform-specific assumptions.
- Impressions are assumed to be greater than or equal to reach.
- Video and short-form content are modeled with higher engagement potential.
- Weekend posts include a small simulated performance boost.
